Regles d'utilisation du logo

  • Ne jamais etirer, deformer ou modifier les proportions du logo
  • Ne pas placer le logo sur un fond trop charge sans ajout d'un conteneur blanc/sombre
  • Respecter un espace vide minimum autour du logo (zone d'exclusion = hauteur du "M")
  • Version claire sur fonds sombres, version sombre sur fonds clairs
  • Taille minimale : 32px pour l'icone, 120px de large pour la version horizontale

Guide d'Utilisation

Recommandations pour une utilisation efficace du kit media sur les differentes plateformes et supports de communication de Melodia Up To Africa.

Facebook Carrousel — Bonnes Pratiques

  • Ordre des slides : Hero (1) → Fonctionnalites (2-5) → Pricing (6) → CTA (8). Le slide Melo (9) est ideal pour retargeting
  • Chaque slide doit etre comprehensible independamment — l'utilisateur peut swiper dans les deux sens
  • Le premier slide (Hero) determine si l'utilisateur continue a scroller — investissez le plus d'impact visuel ici
  • Utilisez le CTA "Commencer" pour les campagnes d'acquisition, "En Savoir Plus" pour la notoriete
  • A/B Test : testez 2 sequences differentes de carrousel pour optimiser le taux de conversion
  • Ciblez les pays africains francophones : CI, SN, CM, ML, BF, NE, GN, BJ, TG, CF
